## 🧑‍💻 À propos

Je suis **AI Engineer** basé à **Paris**, avec **2 ans d'expérience** dans la conception et le déploiement de solutions basées sur les **LLM**, notamment chez **Safran** et **Perions**.

Je travaille principalement sur :

- 🔎 **RAG** : assistants documentaires, recherche sémantique, OCR et pipelines d'ingestion
- 🤖 **IA agentique** : agents autonomes, systèmes multi-agents, orchestration d'outils via MCP
- 📊 **Data Science** : analyse de données, modèles ML/DL, industrialisation

Je m'intéresse à tout ce qui rend les systèmes d'IA **fiables, observables et prêts pour la production**.
